# 🎧 ИзиумГид — веб-аудиогид для музеев с активацией по QR и NFC
 
**Стек:** React 19 · TypeScript · Node.js · PostgreSQL  
**Платформы:** веб-браузер (ПК, смартфон, планшет)

**ИзиумГид** — это веб-приложение мультимедийного аудиогида для музеев. Посетитель открывает маршрут в браузере без установки приложения: сканирует QR-код или касается NFC-метки у экспоната, слушает аудио, смотрит карту, оставляет отзывы. Сотрудники музея управляют контентом через встроенную админ-панель.

Объект внедрения: **Иезуитский коллегиум в Полоцке** (Полоцкий государственный университет).

---

## О проекте

ИзиумГид разработан как дипломный проект и представляет собой полнофункциональное веб-приложение для самостоятельного прохождения музейного маршрута. В отличие от готовых платформ (izi.TRAVEL, SmartGuide и др.), решение не требует мобильного приложения и подписки на сторонний сервис — музей получает собственный аудиогид с полным контролем над контентом.

Посетитель переходит к точке маршрута по ссылке из QR или NFC, прослушивает описание экспоната, отслеживает прогресс и при желании оставляет отзыв. Администратор создаёт точки, загружает аудио и изображения, меняет порядок маршрута и скачивает QR-коды для размещения в зале.

## Сценарий использования

### Основная цель

Получить информацию об экспонате в удобном темпе, не устанавливая приложение и не регистрируясь.

### Путь посетителя

1. Сканировать **QR-код** или коснуться **NFC-метки** у объекта.
2. Браузер открывает страницу точки: название, описание, фото, **аудиоплеер**.
3. После прослушивания обновляется **прогресс маршрута** (локально в браузере).
4. Перейти к следующей точке через карту, список или рекомендации.
5. При желании — **отзыв** или добавление в **избранное**.

### URL точки маршрута

```
/g/{exhibition_slug}/p/{point_slug}
```

Пример: `/g/polotsk-collegium/p/magic-piano`

## Установка и запуск

### Из исходного кода

**Требования:** Node.js 20.19+ (или 22.12+), PostgreSQL.

```bash
# Клонируйте репозиторий
git clone https://github.com/a1inas/museum-audioguide.git

# Перейдите в папку проекта
cd museum-audioguide
```

**Backend:**

```bash
cd backend
cp .env.example .env
# Заполните DATABASE_URL, ADMIN_PASSWORD, ADMIN_COOKIE_SECRET

npm install
npm run dev
```

Сервер по умолчанию: `http://localhost:4000`

**Frontend:**

```bash
cd frontend
npm install
npm run dev
```

Клиент: `http://localhost:5173` (запросы `/api` и `/uploads` проксируются на backend).

### Сборка для production

```bash
cd frontend
npm run build
```

Результат: папка `frontend/dist/`.

### Деплой

| Компонент | Платформа |
|-----------|-----------|
| Frontend | [Vercel](https://vercel.com) |
| Backend + PostgreSQL | [Render](https://render.com) |

В `frontend/vercel.json` настроены прокси `/api` и `/uploads` на backend.

## Ключевые механики

### Активация по QR и NFC

QR-код и NFC-метка содержат одну и ту же ссылку на страницу точки. Отдельного NFC-сервера нет — телефон открывает URL в браузере, сервер отдаёт контент через REST API.

### Прогресс маршрута

Точка считается прослушанной, если аудио доиграно до конца или прослушано ≥ 80 % длительности. Прогресс хранится в **localStorage** браузера (`iziumGuide_listenedPoints`) — регистрация не требуется.

### Отзывы

Посетитель может оставить оценку 1–5, текст, голосовое сообщение и фото. Данные сохраняются в PostgreSQL; администратор модерирует отзывы в админ-панели.

### REST API

Клиент и сервер обмениваются JSON. Публичные эндпоинты — список точек, одна точка, отзывы. Административные — CRUD точек, загрузка медиа, модерация — защищены cookie-сессией после входа по паролю.
